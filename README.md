# Restaurant Orders Data Analysis System

A Python-based data analysis application designed to process, clean, analyze, and manage restaurant order data.

This project demonstrates practical skills in data manipulation, data analysis, Python software architecture, file management, and data exportation using Pandas.

## Project Overview

The Restaurant Orders Data Analysis System is a command-line application that analyzes restaurant orders stored in JSON files.

It processes raw data to generate meaningful business insights, including revenue statistics, restaurant performance, customer activity, and order distribution.

The application also provides CRUD (Create, Read, Update, Delete) operations to manage orders directly from the command line.

## Key Features

### 1. Data Processing

* Load data from JSON files.
* Clean and preprocess raw datasets.
* Transform JSON data into Pandas DataFrames.
* Handle file-related exceptions and invalid data.

### 2. Data Analysis

The application performs several analyses:

* General statistical analysis.
* Total revenue calculation.
* Average order amount.
* Total number of orders.
* Number of delivered and cancelled orders.
* Total commission calculation.
* Revenue analysis by restaurant.
* Revenue analysis by city.
* Order distribution by restaurant.
* Order distribution by status.
* Identification of the best customer.

### 3. Data Management (CRUD)

The application allows users to:

* Add new orders.
* Display existing orders.
* Search for orders using their IDs.
* Update existing orders.
* Delete orders.
* Sort orders in descending order.

### 4. Data Exportation

Analysis results can be exported into multiple formats:

* CSV
* Excel (.xlsx)
* JSON

This makes the generated reports easier to explore and reuse.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/SERGE-DUVAL/Analyse_de_donne_complete.git
```

### 2. Navigate to the project directory

```bash
cd Analyse_de_donne_complete
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

Linux / macOS:

```bash
source .venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## Usage

Run the application using:

```bash
python main.py
```

The application automatically performs an initial analysis and generates reports.

You can then interact with the command-line menu to manage orders and perform additional operations.
